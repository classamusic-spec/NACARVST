# DesignReference

`NACAR_V1_LOCKED_ART_DIRECTION.png` is the **visual source of truth** for the
NÁCAR V1 interface. Open and inspect it before any significant UI work.

`NACAR_UI_SPEC.md` is a written transcription of that image: exact logical
coordinates on the 1536 × 1024 canvas, the material and colour language, and the
list of things that are locked against redesign. It is mirrored one-for-one by
`Source/UI/Layout.h` and `Source/UI/Theme.h`.

> **Note on the binary:** the approved PNG is an image asset and must be placed
> here by hand — it is not generated by the build. Everything the code needs is
> already transcribed into `NACAR_UI_SPEC.md`, so the build does not depend on
> the file being present; but reviewers of UI changes should compare against the
> image itself, not only against the transcription.
